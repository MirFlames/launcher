# Launcher Auto Connect

Клиентский Fabric-мод для подключения к серверу при запуске Minecraft через лаунчер.

## Описание

Мод заменяет кнопки «Одиночная игра» и «Сетевая игра» в главном меню на одну кнопку «Играть», при нажатии на которую происходит автоматическое подключение к серверу из конфигурации. После отключения от сервера игрок возвращается в главное меню, а не в список серверов.

## Конфигурация

IP и порт сервера берутся из **параметров запуска Minecraft** (`--server` и `--port`), если лаунчер их передаёт. Иначе автоподключение отключено (пустой хост, порт 0).

Лаунчер передаёт параметры из `launcher-config.json`:
- **server_host** — хост или IP-адрес сервера
- **server_port** — порт сервера

## Сборка

```bash
./gradlew :mods:launcher_auto_connect:build
```

JAR-файл будет в `mods/launcher_auto_connect/build/libs/launcher_auto_connect-1.0.0.jar`.

## Совместимость

- Minecraft 1.21.11
- Fabric Loader 0.18.4+
- Fabric API
