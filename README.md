## Пройденные тесты (в будущем их надо автоматизировать):
### Успешный тест 1:
1. Пользователь открывает лаунчер.
2. Лаунчер проверяет актуальность версии. Версия неактуально.
3. Лаунчер обновляется и перезапускается.
4. Пользователь не может играть пока не залогинится.
5. Пользователь нажимает на кнопку "войти".
6. У пользователя первый раз открывается телеграм-бот.
7. Телеграм-бот проверяет подписку пользователя на канал сервера. Пользователь не подписан.
8. Телеграм-бот требует подписку с пользователя.
9. Пользователь подписывается и жмет "проверить подписку" у телеграм-бота.
10. Телеграм-бот проверяет подписку, далее проверяет есть ли пользователь в базе. Пользователя в базе нет.
11. Телеграм-бот предлагает пользователю написать свой ник-нейм.
12. Пользователь вписывает ник-нейм.
13. Телеграм-бот валидирует ник-нейм, сохраняет пользователя в базу.
14. Лаунчер опрашивает сервер и получает успех о прохождении пользователем авторизации. Кнопка "играть" становится доступной.
15. Пользователь возвращается в лаунчер и жмет кнопку "играть".
16. Лаунчер обновляет файлы игры: JRE (JDK), библиотеки, ассеты - скачивает из облака mojang / tlauncher, моды - со своего сервера.
17. Лаунчер запускает майнкрафт. Пользователя автоматически подключает к игре.
18. Игра опрашивает сервер на предмет есть ли пользователь в базе. Успех.
19. Пользователь заходит на сервер.
