# Launcher (Wails)

Десктопное приложение на Wails: Go + React + TypeScript.

Документация по разработке — в [CONTRIBUTING.md](../../CONTRIBUTING.md) в корне репозитория:
сборка под все ОС, переменные окружения, архитектура, автообновление, установка JDK,
CI/CD, процесс релиза и накопленные грабли.

Быстрый старт:

```bash
cd frontend && npm install && cd ..
wails dev
```
