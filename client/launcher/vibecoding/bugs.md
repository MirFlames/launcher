# Выявленные недоработки (исправлены)

- ~~Новость дня не загружается после авторизации в лаунчере~~ — **исправлено**: при логине/логауте принудительно обновляется лента новостей (`newsKey`).

- ~~Во время загрузки зависимостей лаунчера скачет оверлей загрузки~~ — **исправлено**: фиксированные `min-width` и `min-height` для контента оверлея.

- ~~Во время загрузки не предусмотрены ретраи~~ — **исправлено**: добавлены ретраи с exponential backoff (3 попытки) для всех HTTP-запросов и скачиваний.

- ~~Во время загрузки необходимо включить VPN~~ — **исправлено**: добавлена поддержка `jdk.download_url` в конфиге бэкенда — можно указать альтернативный URL для JDK (например, зеркало на своём сервере). Ретраи также помогают при нестабильной сети.
